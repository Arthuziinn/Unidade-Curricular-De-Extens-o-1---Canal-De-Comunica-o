# Unidade-Curricular-De-Extens-o-1---Canal-De-Comunica-o
Canal de Comunicação do IFMG Betim para aproximar estudantes e instituição. Por meio de um formulário, é possível enviar dúvidas, sugestões de comunicação e divulgar trabalhos e projetos. Um espaço para participação, troca de informações e valorização da produção acadêmica.
